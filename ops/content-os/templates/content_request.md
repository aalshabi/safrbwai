# طلب محتوى موحّد — سافر بوعي

> انسخ هذا القالب لكل قطعة محتوى. أي حقل فارغ في القسم (أ) يعني أن الطلب لا يدخل مرحلة البحث.
> رقم القطعة يُسجَّل في `content_tracker.csv`، ويتكرر هو نفسه في رابط UTM ورمز واتساب ورقم المنشور.

## (أ) هوية الطلب — يملؤه مدير التحرير

| الحقل | القيمة |
|---|---|
| رقم القطعة | `SBW-YYMMDD-NN` (مثال: `SBW-260925-01`) |
| تاريخ الطلب (الرياض) | |
| سؤال القرار الذي يواجهه القارئ | جملة واحدة تنتهي بعلامة استفهام، مثل: «هل أقسم 7 ليالٍ على مدينتين أم أبقى في واحدة؟» |
| الشريحة | عائلة بأطفال / أزواج / شهر عسل / مسافر منفرد / مجموعة / غير محدد |
| الركيزة | مقارنة فنادق وعروض / شروط الحجز / سفر العائلات / شهر العسل / توزيع الليالي / النقل / تكاليف خفية / تجربة موثقة |
| دليل الحاجة (لماذا الآن؟) | مصدر الإشارة ونوعها: سؤال متكرر في استفسارات Sky، أو ردود على الحساب، أو بحث رائج، أو موسم. اذكر الرابط أو السجل |
| حاجة دائمة أم ترند عابر؟ | دائمة / موسمية / ترند (مع حكم محلل الجمهور) |
| الشكل | ثريد / منشور مفرد / فيديو قصير / صورة مقارنة |
| موعد النشر المستهدف | تاريخ فقط. لا يوجد نشر آلي، وعبدالله ينشر بنفسه |

## (د) الانتقال التجاري — يملؤه مسؤول التحويل

- رابط UTM: `?utm_source=x&utm_medium=social&utm_campaign=safrbwai&utm_content=SBW-YYMMDD-NN`
